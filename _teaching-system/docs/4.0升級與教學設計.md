# 4.0：先讀、再判斷、後回顧

## 為甚麼改

3.1 已提供六款互動題，但入口偏重地圖、篇章查找不便，作答仍容易變成連續試選項。4.0 將閱讀支援放入個人練習，並以平實的導航名稱降低操作門檻。保留原創三國地景、人物、銅金與古紙風格；沒有使用官方遊戲素材。

## 上課前

1. 開啟正式遊戲，搜尋單元或在「出征篇章」選擇。
2. 初次使用建議三關，熟悉後再用五關。
3. 「閱讀支援模式」預設開啟：先點選一段原文和作答把握，然後作答；讀解釋後選一句反思。
4. 學生較熟練時可取消支援模式，直接作答。設定僅適用之後開始的新練習。
5. 選「未肯定」不扣分。閱讀記號及反思也不加分，不能當作理解能力評分。

## 學生沒有裝置

按「十分鐘課堂教學指引」查看流程，再開「老師帶讀／課堂攻城」。教師先示範一題的思考，學生紙筆留下自己的答案，兩人比較原文證據，同時亮板，再用另一色訂正。每題交換讀句、找證據、說理由的角色。教師按判斷、證據及解釋分開給分。

## 觀察是否有幫助

連續三節課各抽取相近難度的三題，記錄：

- 討論前已留下個人答案的人數。
- 能指出支持答案的原文的人數。
- 訂正後隔日能重新作答的人數。

不要只比較軍功總分：題目難度、提示、猜測和參與機會都會影響分數。本版本沒有經過課堂成效研究，不能保證提高動機或成績。支援模式的選線索屬自我標記，沒有自動評判證據是否有效。

## 系統結構

| 模組 | 責任 |
|---|---|
| `app.js` | 啟動、入口、身份表單、導航、連線與分享 |
| `session.js` | 課堂／個人練習、既有計分、戰報、錯題及列印 |
| `learning.js` | 閱讀記號、作答把握、反思、篇章搜尋、教學指引 |
| `live.js` | 房間同步、主持及提交；相同狀態不重畫介面 |
| `teacher.js` | 教師題庫及報告入口 |
| `interactive-core/ui/author.js` | 六題型的驗證、作答及編題 |
| `remote.js` + Apps Script | 經來源檢查的通訊、教師驗證、Google Sheets 回存 |

建置時將功能模組合成帶內容雜湊的靜態資源，無新增執行依賴。Google Sheets 結構及原有計分格式保持兼容；4.0 前端可使用已部署的第62版後端。舊 Apps Script 直接遊戲頁可能仍顯示3.1；正式入口以 GitHub `play.html` 為準。

## 私隱與限制

- GitHub 僅包含程式、圖像和通用示例，沒有學生名單、成績或教師密碼。
- 正式成績仍在私人 Google Sheets，教師報告仍需後端登入。
- 個人閱讀記號、反思及待請教題目只保留於當前瀏覽器分頁的練習資料，**不送到教師成績表**；自行匯出戰報時會包含這些欄位。
- 關閉分頁後可能失去這些本機記號；它們不是跨裝置學習檔案。
- 學生身份仍自行填寫，適合練習，不是防冒認考試系統。
- 房間是定期查詢，仍可能有數秒延遲；有新參與者或房間階段改變時仍需更新畫面。
- 手機和平板尺寸的瀏覽器測試不等於實體 iPad Safari 或全班併發壓力測試。

## 設計依據及協作

以明確示範、提示及逐步獨立的方向設計，參考 [EEF：Metacognition and Self-Regulated Learning](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/metacognition)。這是設計依據，並非本遊戲成效證據。

Gemini 協助草擬閱讀提示、非洩題回饋、反思選項及無裝置活動流程，經人工式內容審閱及改寫後整合；未向 Gemini 提供學生資料、密碼或私人題庫。程式實作、驗證及發佈由本專案工作流程處理。
