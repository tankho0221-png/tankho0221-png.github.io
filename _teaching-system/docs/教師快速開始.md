# 出師北伐 3.1：教師快速開始

## 網址與使用方式

- 正式入口：https://tankho0221-png.github.io/online-teaching-system/
- 正式遊戲：https://tankho0221-png.github.io/online-teaching-system/play.html
- 示範版：https://tankho0221-png.github.io/online-teaching-system/demo.html

正式版畫面會顯示「軍情已接通」及 Google Sheets 題數。示範版會清楚顯示「本機示範」，不儲存到教師的試算表。

學生沒有 iPad 的課堂：老師選篇章，開「課堂攻城」，學生紙筆／白板先答，再討論、亮板、揭曉。以「判斷、證據、解釋」分別給分。

學生可用裝置時：可開「單騎研習」，或由老師在「烽火連營」建立房間，學生輸入六位碼。答題全用點選；配對、排序也支援拖動把手，是非題支援左右滑動。班別、學號等入場資料仍需輸入。

## 最簡單的加題方法

### 原有選擇題

1. 在試算表準備七至九欄：篇章、原句、目標字詞、正解、錯項1、錯項2、錯項3、提示、解釋。
2. 複製範圍，在遊戲「教師督學」登入，按「貼上新題目」。
3. 貼上、檢查預覽，再按「確認加入題庫」。一次最多100題。相同篇章、原句及目標詞的題目不會重複加入。

也可直接在 `QuestionBank` 最末行加題，再按「重新讀取題庫」。四個選項須不同，首七欄不可留空。原有 HTML 標記會轉成純文字顯示。

### 六款互動題

「教師督學 → 新增互動題 → 選題型 → 填表 → 預覽並試玩 → 確認加入題庫」。

| 題型 | 老師怎樣輸入 | 學生怎樣答 |
|---|---|---|
| 連環配對 | 每行「詞語 \| 正確意思」，2–6組 | 選卡再選位置，或拖動把手 |
| 時序布陣 | 按正確順序每行一項，3–6項 | 上下移動或拖動排序 |
| 分營歸類 | 每行「句子 \| 類別」，2–3類 | 選卡再選類別，或拖動 |
| 輿圖尋蹤 | 地點名稱、背景、正解編號 | 點地圖標註或下方地點按鈕 |
| 是非軍令 | 判斷句及是／非正解 | 左右滑動或點是／非，然後確認 |
| 去偽存真 | 四項解釋及唯一正解 | 劃去三個錯項，確認留下的答案 |

點圖使用預設標註位置；教師須核對题幹與圖上的方位相符。背景是原創示意圖，並非歷史地理資料。互動題存在私人 `InteractiveBank` 工作表；JSON欄由表單自動處理，不需要手寫。

「預覽六款示範題」可一次檢查六個示例並加入私人題庫。相同題型、篇章與題幹不會重複新增；如要修改，請先備份，再在試算表修改相應資料。

## 計分與資料

- 個人練習：首次獨立答對3分，使用提示或訂正後答對1分；略過0分。互動題以整題完成作判斷，最多12次不同嘗試。
- 多人房間：開放作答後每題提交一次；由 Google 後端判分，揭曉前不向学生發送正解或分數。
- 課堂攻城：老師按學生的判斷、證據、解釋給軍功，與個人成績分開記錄。
- 新版成績儲存到 `RecordsV2`，作答快照在 `RunsV2`；原有 `Records` 歷史資料保留。
- 正式版的恢復進度、個人錯題畫面暫存在瀏覽器分頁儲存空間，並非跨裝置登入服務。共用裝置使用後關閉分頁。
- 學生身份由班別、學號自行填報，適用練習，不能當作防冒認的正式考試系統。

## 開源及私隱

GitHub 放程式、原創圖像與通用示例。學生資料、成績、私人題庫及教師密碼留在 Google。試算表使用「受限制」分享；不要重新開放「知道連結的任何人」。

教师密碼只在 Apps Script 的 `TEACHER_PASSWORD` 指令碼屬性設定。不要把密碼、班別名單或試算表匯出檔提交到 GitHub。老師登入及成績報告由後端驗證。
